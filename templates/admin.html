How It Works

1
Upload Payload — upload blossom.exe / bloom.dll below. One universal loader is built for all users.
2
Build Loader — run build.bat in the blossom/ folder. It fetches the encrypted payload from here and compiles one loader.
3
Upload Latest — upload the compiled zip to "Latest Loader" below. The updater auto-downloads it for users.
4
Manage Licenses — create keys on EliteAuth. Users enter their EliteAuth license key in the loader.
